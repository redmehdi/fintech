# Claude Code project instructions

**Start by reading `AGENTS.md`.** It is the authoritative shared coding policy for this repo, applicable to both Claude Code and Codex. Then read the PRD, architecture, OpenAPI specification and the assigned backlog ticket. Follow the scope and constraints exactly. Never build real-money execution in this simulation-only MVP.

Before proposing a code change, identify the ticket ID, planned files and tests. After implementing, provide tests executed, API/schema compatibility notes and any unresolved concerns.

For the pair-programming CLI, see [QUICKSTART.md](QUICKSTART.md). After Claude implements a ticket, the pipeline keeps the same Codex session for follow-up reviews.
